# D4 (Int/Int `/`): experiment arms and typed census, W8-08

Base: aether 7f58a33 (language 2026-10-07-1). The arms are
`AETHER_EXPERIMENT=div=<rule>` (src/aether/experiment.c), a post-order visitor
on the W7-24a oracle walk. It runs after rea's semantic pass, over the main
program and every loaded module. At each `/` whose two operands the oracle
types as Int, it classifies the use the parent puts the quotient to, then:

| use of the quotient | current | A `int` | A+ `intplus` | B+ `realplus` | ctx |
|---|---|---|---|---|---|
| Int sink: typed `let`, assignment, `ret` from `-> Int`, Int parameter, record field | Real, truncated at the sink | integer | integer | Real, truncated | integer |
| Int builtin argument (`int_to_text`, `chr`, `copy`, `setlength`, ...) | Real | integer | integer | **DIV-001** | integer |
| index, `loop` upper bound, `%` / `div` operand | Real | integer | integer | **DIV-001** | integer |
| Real sink (typed `let`, Real parameter, `ret` from `-> Real`, Real builtin argument) | Real | integer | **DIV-001** | Real | **DIV-001** |
| `*`, `/`, comparison, print, inferred `let`, untyped argument | Real | integer | integer | Real | **DIV-001** |

`+` and `-` pass their parent's use to both operands, so a `+`/`-` chain into
an Int sink counts as that sink. Under A and A+, an inferred
`let q = a / b;` is retyped to Int, as a real A rule would type it. A `/`
with an operand the oracle cannot type is logged `unknown` and left as
today. DIV-001 reads: "...Write `a div b` for the integer quotient, or
`real(a) / b` for the Real one."

## Program outcomes against the shipped rule

1,675 programs run (17 compile-only: network). The corpus has a golden stdout
for 734 of them.

| arm | stdout changes, rc 0 both | newly rejected (DIV-001) | corpus golden pass to fail | fail to pass |
|---|---|---|---|---|
| A `int` | 9 | 0 | 7 | 0 |
| A+ `intplus` | 1 | 8 | 7 | 0 |
| B+ `realplus` | 0 | 2 (archive) | 0 | 0 |
| ctx | 1 | 9 | 8 | 0 |

Per program (`div_waivers_2026-10-07.json` holds each one's old and new rc
and stdout):

- `corpus/200..205, 207_real_mean_*` (7 programs, `let average: Real = sum / n`):
  A prints `78.00` for `78.75`, silently wrong. A+ and ctx reject them. B+
  leaves them unchanged.
- `examples/base/barnsley_fern`: A silently draws a different fern. A+ and
  ctx reject it.
- `corpus/06-29a_gemini_..._design_by_contract` (`(a / gcd) * b`, exact
  division): A and A+ leave it unchanged. Only ctx rejects it: a correct
  program that pays ctx's `*` rule.
- `tests/extension_call_alias_pass`: a `-> Int` function that does
  `ret a / b` prints `5.000000` today. A `ret` does not truncate to the
  declared Int, which is a separate defect. A, A+ and ctx print `5`.
- `archive/17d52aff7aab`, `archive/72062c57d4c8` (`xs[n / 2]`, correct today
  through index truncation): only B+ rejects them.

Dual run, shipped rule against A: **0 programs need integer semantics**
(nothing fails today and passes under A). **8 need Real semantics** (7 corpus,
1 example). This matches the plan's preliminary census, now made with the
oracle. Existing programs still cannot choose between A and ctx. They put a
price on each: A is silently wrong on 8 Real-intent programs, ctx rejects
those 8 plus 1 correct composition, and B+ rejects 2 correct index uses.

## Not done here

- The probe, the decider under D4's pre-registered rule (≥30 tasks, 4
  untrained models × 5, card-v1 with no `/` sentence), needs the rig and the
  umbrella's W1 trap tasks. The arms are ready for it:
  `tools/aether_first_attempt_histogram.py --recompile --experiment div=<rule>`
  grades stored generations under any arm. The census tool does the same for
  plain source sets.
- Compound `x /= y` lowers to an assignment, not a `/` node. The arms leave it
  alone and the log does not count it.

## Commands

```sh
L=<scratch>/divlogs
tools/aether_experiment_census.py \
  --arm base=<7f58a33>/aether: --arm head=build/aether: \
  --arm "current=build/aether:;AETHER_EXPERIMENT_LOG=$L/current.tsv" \
  --arm "int=build/aether:div=int;AETHER_EXPERIMENT_LOG=$L/int.tsv" \
  --arm "intplus=build/aether:div=intplus;AETHER_EXPERIMENT_LOG=$L/intplus.tsv" \
  --arm "realplus=build/aether:div=realplus;AETHER_EXPERIMENT_LOG=$L/realplus.tsv" \
  --arm "ctx=build/aether:div=ctx;AETHER_EXPERIMENT_LOG=$L/ctx.tsv" \
  --tests tests --examples examples --corpus <manifest> --corpus-root <umbrella> \
  --fixtures <umbrella>/Tests/aether_specialization/fixtures --dir <archive> \
  --nondeterministic <17 keys> --waivers div_waivers_2026-10-07.json --json div.json
tools/aether_census_sites.py --invocations 2 --set tests=tests --set examples=examples \
  --set corpus=<corpus dir> --set archive=<archive> current=$L/current.tsv ctx=$L/ctx.tsv ...
```
