**Aether is a small, statically-typed programming language designed to be
written by language models.** A model should be able to write valid, correct
Aether with little or no reference in its prompt, and the language has been
shaped by measuring what models actually write: a construct they keep reaching
for gets added, a construct that fools them gets a coded diagnostic that names
the fix.

## What 1.01 is

The first release after 1.0. It carries languages `2026-11-18-1`,
`2026-11-24-1`, `2026-11-24-2` and `2026-11-28-1`: what `main` held when the
owner declared it on 2026-11-28. The
[CHANGELOG](https://github.com/emkey1/aether/blob/1.01/CHANGELOG.md) lists every
change under those versions.

`aether --version` prints `Aether Compiler Version: 2026-11-28-1 (1.01)`.

## The freeze, and what 1.01 changes for a 1.0 program

1.0 froze the language (decision D75): a program that is valid under 1.0 keeps
compiling and printing the same output. Since 2026-11-28 the one exception
reads: a 1.0 behaviour that is silently wrong under the specification may
become a coded error, or give the output its decision row states, with that row
and the evidence for it. Under it:

- the TOON-001 and MS-001 handle checks read every statement, not every line
  (D90);
- `\xNN` and an octal Text escape name a code point, as `chr` does (D92);
- a JSON integer from 2^63 to 2^64-1 is a real, not a negative `Int` (D93);
- a `Real` with no `Int` value stops the program when stored in an `Int`
  (D94);
- a negative Text slice bound is ARR-003, not `""` (D95).

**Two freeze breaks.** These stop programs that ran correctly under 1.0, and
the owner accepted them as breaks on 2026-11-24: a name an imported module
exports as a `const` is NAME-001 (D91), and a wrong argument count on a math
builtin is BUILT-002 at compile time (D96). None of the 6,716 distinct
model-written programs archived with the benchmark, and none of the 218 replay
programs, uses either form.

Also visible to a 1.0 program: one stopped by Ctrl-C exits 130 instead of 0 or
1 (D89), and the builtin listings count one more builtin in the `user`
category.

## Other changes

- Reading a Text by character (`t[i]`, a slice, `loop c in t`, `length`) is
  about 25 times faster.
- An index into an empty array is ARR-003, not an uncoded VM error.
- `True`, `False`, `None`, `null` and `NULL` are SCOPE-001 with a hint naming
  `true`, `false` or `nil`.
- Messages that named the wrong thing are fixed (PAR-001 on a shared array,
  the ANN-001 hint for an `@post` on an array result, a Real slice bound,
  `join` of an `Int[]`).
- `pollkeyany()` runs on every build, with the `io` effect class.
- While VM threads run, a by-value read is a real copy.
- `has_builtin` answers for a core builtin under any category again, as at
  1.0.
- `--help` lists `--version`, `--deny`, `--fx-record` and `--fx-replay`.

**Silent-wrong gate (KPI S).** No benchmark board yet measures silently wrong answers
on 1.0 or later, so this release reads that gate by paired replay instead: of
the 274 archived first attempts and 43 repair attempts, none moves into a
silently wrong answer on the 1.01 binary, and no regression is unwaived.

## Install

Each archive holds `bin/aether`, the examples under `share/aether/examples`, the
manual and guides under `share/doc/aether`, and the license files. Check a
download against `SHA256SUMS`.

**macOS (Apple silicon).** Needs macOS 15 or later. The binary is not signed
or notarized, so clear the quarantine flag after a browser download:

```sh
tar -xzf aether-1.01-macos-arm64.tar.gz
xattr -d com.apple.quarantine aether-1.01-macos-arm64/bin/aether
aether-1.01-macos-arm64/bin/aether --version
```

**Linux (x86_64).** Needs glibc 2.38 or later (Ubuntu 24.04 or newer, for
example) and the libcurl and SQLite runtime libraries, `libcurl.so.4` and
`libsqlite3.so.0` (`libcurl4t64` and `libsqlite3-0` on Ubuntu 24.04). On an
older distribution, build from source.

**From source.** `aether-1.01-src.tar.gz` is the tag with its `rea` and
`pscal-core` submodules filled in; GitHub's own "Source code" archives leave
`external/` empty and do not build. Or clone the tag:

```sh
git clone --recurse-submodules --branch 1.01 https://github.com/emkey1/aether.git
cd aether
cmake -S . -B build && cmake --build build -j
./build/aether --no-cache program.aether
```

You need CMake, a C compiler and the libcurl development headers (`brew install
curl` on macOS, `libcurl4-openssl-dev` on Debian and Ubuntu); configure with
`-DAETHER_ENABLE_CURL=OFF` for a build without networking.

## Known at 1.01

- `length` applied directly to a `ToonNode` that your own function returns, or
  read from an array element or a record field, stops at run time without a
  diagnostic code ("len expects a string or array argument."). Held in a typed
  local, the same node is TOON-001 at compile time.
- The conformance pack expects two engine failures (W5-13, width specifiers;
  W5-08, empty-array equality).
