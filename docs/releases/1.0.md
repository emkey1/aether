**Aether is a small, statically-typed programming language designed to be
written by language models.** A model should be able to write valid, correct
Aether with little or no reference in its prompt, and the language has been
shaped by measuring what models actually write: a construct they keep reaching
for gets added, a construct that fools them gets a coded diagnostic that names
the fix.

```aether
@pure
fn classify(score: Int) -> Text {
    if score >= 90 { ret "distinction"; }
    if score >= 70 { ret "merit"; }
    ret "pass";
}

fn main() -> Void {
    fx { println("Ava: ", classify(92)); }   // Ava: distinction
    ret;
}
```

## What 1.0 means

1.0 freezes the language (decision D75). A program that is valid under 1.0
keeps compiling and printing the same output in every later 1.x release: no
renames, no removed forms, no changes of meaning. New builtins, new syntax that
used to be an error, better diagnostics, performance work and bug fixes still
come. The one exception is a 1.0 behaviour that is silently wrong under the
specification, which may become a coded error with its own decision row and a
hint naming the fix.

1.0 follows seventeen betas (`1.0-beta1` on 2026-10-20 to `1.0-beta17` on
2026-10-27) and their reviews by an independent agent that writes and runs
Aether through an MCP runner. Its final pass on this code, covering
diagnostics, arithmetic, overflow traps and timing, ended "clear to tag 1.0".
On top of `1.0-beta17` this release carries the fixes from those last reviews;
the [CHANGELOG](https://github.com/emkey1/aether/blob/1.0/CHANGELOG.md) lists
them under 2026-10-30-1.

`aether --version` prints `Aether Compiler Version: 2026-10-30-1 (1.0)`: the
date version that tools pin to, then the release label.

## Install

Each archive holds `bin/aether`, the examples under `share/aether/examples`, the
manual and guides under `share/doc/aether`, and the license files. Check a
download against `SHA256SUMS`.

**macOS (Apple silicon).** Built on macOS 15. The binary is not signed or
notarized, so clear the quarantine flag after a browser download:

```sh
tar -xzf aether-1.0-macos-arm64.tar.gz
xattr -d com.apple.quarantine aether-1.0-macos-arm64/bin/aether
aether-1.0-macos-arm64/bin/aether --version
```

**Linux (x86_64).** Built on Ubuntu 24.04 (glibc 2.39); it needs the libcurl and
SQLite runtime libraries (`libcurl4t64` and `libsqlite3-0` on Ubuntu 24.04). On
an older distribution, build from source.

**From source.** `aether-1.0-src.tar.gz` is the tag with its `rea` and
`pscal-core` submodules filled in; GitHub's own "Source code" archives leave
`external/` empty and do not build. Or clone the tag:

```sh
git clone --recurse-submodules --branch 1.0 https://github.com/emkey1/aether.git
cd aether
cmake -S . -B build && cmake --build build -j
./build/aether --no-cache program.aether
```

You need CMake, a C compiler and the libcurl development headers (`brew install
curl` on macOS, `libcurl4-openssl-dev` on Debian and Ubuntu); configure with
`-DAETHER_ENABLE_CURL=OFF` for a build without networking.

## Known at 1.0

- `length` of a `ToonNode` that comes from your own function, an array element
  or a record field stops at run time without a diagnostic code.
- The conformance pack expects two engine failures (W5-13, width specifiers;
  W5-08, empty-array equality).
- The prior-alignment card is over its 2,000-token budget under the Qwen3.5
  tokenizer (2,126; 1,984 under o200k).
